# TaskFlow – Student Task Manager

**Project Description:**

TaskFlow is a web-based Student Task Management application designed to help students organize, manage, and track their daily academic tasks efficiently.

**Technologies Used:**
- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Cloud Firestore

**Key Features:**
1. User Registration and Login
2. Secure Authentication
3. Add New Tasks
4. Edit Existing Tasks
5. Delete Tasks
6. Mark Tasks as Completed
7. View Pending and Completed Tasks
8. Real-Time Task Synchronization with Firebase
9. Task Progress Dashboard

**How to Run the Project:**
1. Extract the ZIP file.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.
6. Register or log in to access the TaskFlow dashboard.

**Project Objective:**

The main objective of TaskFlow is to improve students' productivity, time management, and task organization through a simple, user-friendly, and efficient web application.
